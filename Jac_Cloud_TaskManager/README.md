# Jac Cloud Task

This project uses the Jac language and Jac Cloud tools.

## Project Structure
- `main.jac`: Main Jac source file.
- `mydatabase/`: Directory for database/storage configuration.
- `requirements.txt`: Python dependencies for Jac language and Jac Cloud.

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Use Jac tools to run or deploy your Jac code.

## Requirements
- jaclang
- jac-cloud
